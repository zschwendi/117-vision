# Choose your 117 download

| Device | Package | Instructions |
| --- | --- | --- |
| iPhone or iPad | [iOS 130.1 preview](https://github.com/zschwendi/117-vision/releases/tag/ios-v130.1-preview) | [Windows/Linux installation](IOS-SIDELOADING.md); paid developer signing required |
| Apple Vision Pro | [visionOS preview](https://github.com/zschwendi/117-vision/releases/tag/visionos-v130.1) | [Windows/Linux installation](SIDELOADING.md) |
| Apple Silicon Mac, macOS 26.0+ | [Native Mac 130.1 preview](https://github.com/zschwendi/117-vision/releases/tag/macos-v130.1-preview) | [Mac setup and desktop-preview limits](MACOS.md) |

An ARM64 processor is only one compatibility requirement. iPhone/iPad share the iOS package; visionOS and macOS require their own packages. Windows and Linux can run the sideloading tool, but these Apple packages do not run as Windows/Linux games. Apple TV, Android and Intel Macs are not covered by these downloads.

All downloads are experimental and require your own supported game files. Check the release's OS, memory, signing and validation notes before installing.
